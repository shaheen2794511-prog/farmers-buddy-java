🌾 Farmers Buddy

Farmers Buddy is a Java-based web application designed to provide farmers with a centralized platform for accessing agricultural information, services, market-related information, training resources, and communication features.

The project provides different modules to help farmers interact with agricultural resources and access useful farming-related information.

## 🚀 Features

- 👤 User registration and login
- 🌾 Farmer-focused dashboard
- 🛒 Commodity and market information
- 🔍 Search functionality
- 📊 Market and commodity details
- 🌱 Soil-related information
- 🎓 Farmer training and training requests
- 📩 Inbox and messaging functionality
- 📧 Email-related features
- 🗺️ District-based information
- 🔐 Password management and recovery
- 👨‍🌾 Farmer profile management
- 📋 Agricultural information management

## ⚙️ Requirements

Before running the project, make sure the following are installed:

- Java JDK
- Apache Tomcat
- MySQL
- Apache Ant
- NetBeans IDE

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/shaheen2794511-prog/farmers-buddy-java.git
```

2. Open the project in NetBeans.

3. Configure MySQL according to the application's database configuration.

4. Configure Apache Tomcat as the application server.

5. Build and deploy the application.

6. Start the application using Tomcat.

7. Open the application in your browser using the configured local server URL.

## 🗄️ Database

The application uses MySQL as its database.

Before running the application:

1. Install MySQL.
2. Create the required database.
3. Import the required database/schema.
4. Update the database connection settings.
5. Make sure the MySQL server is running.

> **Note:** Do not commit real database passwords or other sensitive credentials to the repository.

## 🎯 Project Objective

The main objective of Farmers Buddy is to provide farmers with a digital platform where they can access agricultural resources, market information, training opportunities, and other farming-related services through a single web application.
